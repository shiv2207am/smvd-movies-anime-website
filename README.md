# SMVD – Movies & Anime Website 🎬🍿

SMVD is a **modern Movies & Anime showcase website** inspired by popular streaming platforms.  
It features a cinematic carousel UI, smooth navigation, and an engaging visual experience built using **HTML, CSS, and JavaScript**.



## ✨ Features

- Interactive movie & anime carousel slider
- Modern streaming-platform inspired UI
- Download & trailer buttons
- Embedded video preview player
- Search bar UI
- Responsive header navigation
- Custom favicon & branding
- Smooth animations and transitions



## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **Google Fonts (Montserrat)**
